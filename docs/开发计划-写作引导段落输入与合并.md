# 开发计划：

写作引导（我还没写 → 写作引导 → 段落写作提示）增加“每段文本输入 + 合并成稿 + 跳转我写完了”。

- 日期：2026-08-24
- 页面：public/index.html（视图：#view-brainstorm）
- 脚本：public/app.js

## 1. 目标与范围
- 在每张“段落写作提示”卡片下方追加一个文本域，供学生写本段内容。
- 页面下方新增“我写完了”按钮：收集各段输入，合并为完整草稿，自动跳转到“我写完了”视图并回填到 #draftInput。
- 仅改前端 UI/交互，不依赖后端（有 API 时亦兼容）。

## 2. UI 设计
- 每个段落卡片（.paragraph-guide-card）下方插入 <textarea class="user-write-input" data-user-paragraph-index=">=1">。
- 占位：“在这里写这一段…”，默认行高 5 行，100% 宽。
- 卡片区域下方追加一行操作区：
  - 按钮：“我写完了”（class: primary）
  - 字数汇总提示：“当前合并字数：N”（实时更新）。
- 配色与圆角沿用现有主题变量，保持统一视觉风格。

## 3. 交互流程
1) 进入“我还没写”并生成写作引导后，自动为每段插入文本域。
2) 学生逐段填写。
3) 点击“我写完了”：
   - 收集所有段落文本（按卡片顺序），过滤空行，用空行连接。
   - 若全部为空：提示“请先在每段输入框中写入内容”。
   - 将合并文本写入 #draftInput，并触发 input 事件。
   - 切换到视图 #view-revise（相当于点击侧边栏“我写完了”）。

## 4. 技术方案
- 方案 A（快速稳定）【推荐】：在 renderWritingGuide() 渲染内容后，调用 bindParagraphInputs()，以 DOM 方式为每个 .paragraph-guide-card 追加 <textarea>；在段落列表区域末尾插入操作区与“我写完了”按钮。
- 方案 B（模板内嵌）：修改 renderParagraphGuides()，让每张卡片的模板自带 <textarea>。优点：结构更直观；缺点：修改模板函数较多，回归量略大。
- 本次采用方案 A，改动面更小，便于回退。

## 5. 关键实现点（伪代码）
    function bindParagraphInputs(){
      const list = document.querySelectorAll('.paragraph-guide-card');
      const created = [];
      list.forEach((card, idx) => {
        if (card.querySelector('textarea.user-write-input')) return;
        const ta = document.createElement('textarea');
        ta.className = "user-write-input";
        ta.rows = 5;
        ta.placeholder = "在这里写这一段…";
        ta.setAttribute('data-user-paragraph-index', String(idx + 1));
        card.appendChild(ta);
        created.push(ta);
      });
      insertFinishRow(created);
    }

    function insertFinishRow(areas){
      const container = document.querySelector('.writing-guide-panel');
      const row = document.createElement('div');
      const btn = document.createElement('button');
      const wc = document.createElement('span');
      btn.textContent = "我写完了";
      btn.className = "primary";
      function recompute(){
        const text = areas.map(t => t.value.trim()).filter(Boolean).join('\n\n');
        wc.textContent = text ? `当前合并字数：${text.length}` : "";
        return text;
      }
      areas.forEach(t => t.addEventListener('input', recompute));
      btn.addEventListener('click', () => {
        const combined = recompute();
        if(!combined){ alert('请先在每段输入框中写入内容'); return; }
        const main = document.getElementById('draftInput');
        if(main){ main.value = combined; main.dispatchEvent(new Event('input', { bubbles: true })); }
        const tab = document.querySelector('.nav-item[data-view="revise"]');
        if(tab) tab.click(); else setView('revise');
      });
      row.append(btn, wc);
      container.appendChild(row);
    }

## 6. 状态与可用性

## 8. 验收标准（AC）
- 生成写作引导后，**每个段落卡片**下方均出现文本框。
- 输入任意三段，点击“我写完了”：
  1) 按钮出现“正在加载中”后恢复；
  2) 自动跳转到“我写完了”；
  3) 合并文本出现在 #draftInput；
  4) 再点击“生成体检报告”能得到结果卡片（或预览卡片）。
- 所有交互在无后端情况下也能工作（走前端回退逻辑）。

## 10. 风险与缓解
- 风险：未来调整“写作引导”DOM 结构可能影响挂载位置。
  - 缓解：以类名 .paragraph-guide-card 与 .writing-guide-panel 为锚点，失败时安全跳过，不阻塞其他功能。
- 风险：学生输入较长，性能与布局抖动。
  - 缓解：文本域默认 5 行，浏览器自带滚动；不做富文本。
