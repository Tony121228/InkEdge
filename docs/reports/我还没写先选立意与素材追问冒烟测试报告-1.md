## 五、问题清单

### P1 重要：真实 DeepSeek 输出与题目分析严格契约不稳定

- 表现：真实请求在题目分析阶段被 `TOPIC_ANALYSIS_INVALID` 拒绝。
- 影响：用户无法看到立意，更无法进入素材追问与写作引导。
- 原因：模型将 `riskyAngles[0]` 返回为非对象类型，而服务端契约要求对象。
- 建议：让题目分析提示词与服务端规范化器使用同一份明确 JSON 示例和字段约束，并为真实模型输出增加针对性契约测试；不应降低“3 个有效立意”的核心质量门槛。

### P1 重要：名为 DeepSeek 的自动测试已落后于当前契约

- 表现：本地假模型只返回 1 个立意，用例因 502 失败。
- 影响：指定自动测试集无法全绿，且名称容易让人误以为它验证了真实 `.env` DeepSeek。
- 原因：测试夹具未随新契约同步更新。
- 建议：将假模型的题目分析返回改为 3 个完整、唯一、信息量达标的立意，并修正断言失败时的 HTTP 服务清理。如需验证真实 DeepSeek，应另设明确的 real-AI 脚本。

### P3 提示：测试环境未配置 `APP_SECRET`
