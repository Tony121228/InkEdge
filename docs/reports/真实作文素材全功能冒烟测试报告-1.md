## 总体结论

当前项目的主要写作辅导能力不是空壳：7 天训练计划、作文体检、局部修改、素材保存读取、能力诊断接口均有可用证据。尤其 7 天训练计划已经能用真实 DeepSeek 调用完成从输入素材到分阶段生成、写作、诊断、复盘的完整路径。

但本轮测试发现两类需要优先处理的问题：

1. 短期“我还没写”的核心 `guided-writing` 接口存在真实模型 JSON 解析不稳定，3 次真实调用中 2 次失败，可能直接阻断“生成写作引导”。
2. 成长地图当前仍偏空壳，能力测评、训练任务提交后，`/api/v1/growth/timeline` 仍返回空时间线和空能力变化。

## 问题清单

| 优先级 | 问题 | 表现 | 可能原因 | 建议修改 |
|---|---|---|---|---|
| P0 阻断 | 短期 `guided-writing` 真实 AI 解析不稳定 | 同一真实素材 3 次调用中 2 次返回 500，错误码 `MODEL_JSON_PARSE` | 输出字段变多后单次 JSON 体较大；解析函数只接受严格 JSON；`MODEL_JSON_PARSE` 被设置为不可重试 | 将短期写作引导拆成“提纲树”和“段落提示”两个模型调用，或对该接口加入一次 JSON 修复/重发策略；失败时保留已有提纲与追问 |
| P1 重要 | 作文会话缺少用户归属校验 | 用户 B 可通过 sessionId 读取用户 A 的会话和素材 | `assertEssaySession()` 只按 id 查找，没有校验 owner/studentId | 会话查询和写入均增加当前用户校验；不匹配返回 404 或 403 |
| P1 重要 | 成长时间线接口为空 | 能力画像、训练计划、任务提交后，`timeline`、`abilityChanges` 仍为空 | `/api/v1/growth/timeline` 当前直接返回空数组，只附带最近作文里程碑 | 从能力画像、训练提交、作文诊断、训练计划状态聚合生成成长节点 |
| P1 重要 | 成长页仍为空 | 测评后页面仍显示“成长地图暂时为空” | 前端依赖空的 timeline 接口，缺少降级展示能力变化 | 后端先生成 timeline；前端展示阶段、最近变化、已完成训练和下一步建议 |
| P1 重要 | 前端年级选择缺少小学年级 | API 可接收“五年级”，但 app 页面只能选初一到高三 | `public/app.html` 的 `#gradeInput` 只配置初高中选项 | 增加三年级到六年级，或改为可输入年级 |
| P2 一般 | 体检页分数显示为 0 | API 返回对象型分数时，前端 score card 显示 0 | 前端未兼容 `{score, level, evidence}` 结构 | 渲染分数时读取 `item.score`，并展示证据和建议 |
| P2 一般 | 素材库 UI 展示不足 | 保存后只显示素材 ID 和完整度，不显示用户输入的素材锚点 | 页面只渲染提交结果，缺少素材列表和读回视图 | 增加素材卡列表，显示场景、人物、动作、细节、可用于哪类题目 |
| P2 一般 | 能力诊断页面说服力不足 | 页面只展示阶段、优势、短板，未展示 8 维分数和证据点评 | UI 没有完整消费能力画像字段 | 增加八维能力雷达或列表、证据、建议训练焦点 |
| P2 一般 | 局部修改可能补入新事实 | `keepFactsStrict=true` 时示范片段仍加入原文没有明确提供的细节 | 模型示范倾向具体化，提示词约束还不够硬 | 示例句仅改写原文已有事实；新增细节用问题式占位让学生自己补 |
| P2 一般 | 训练计划 API 仍接受 14/30 天 | 前端无入口，但直接请求 `planType=14d/30d` 仍返回 200，且 days/totalDays 不一致 | 后端保留旧 planType 输入兼容 | API 层只允许 `7d`，或把非 7 天请求统一拒绝为 400 |
| P3 优化 | 完成后的计划不在 active 中返回 | 7 天计划完成后 `/training-plans/active` 为空 | active 接口只返回进行中计划 | 如产品希望复盘页继续展示最近计划，可增加 recentlyCompletedPlan 字段 |
| P3 优化 | `studentTask` 文案偶有不贴合 | 已生成段落提示时仍可能提示“请回答以下问题” | 模型字段没有严格区分追问阶段和写作阶段 | 后端根据 `nextAction` 自动兜底生成明确任务文案 |
