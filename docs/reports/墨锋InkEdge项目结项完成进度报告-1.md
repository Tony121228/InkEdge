## 二、项目定位与本期目标

墨锋 InkEdge 面向中小学生、家长和写作辅导场景。产品不是简单替学生生成一篇作文，而是把写作拆成可以理解、选择、练习和复盘的步骤，让学生保留真实经历并逐步形成自己的表达。

本期目标包括：

- 建立题目理解、立意选择、素材追问、提纲和分段写作引导。
- 建立作文体检、优先问题、局部修改、参考对照和复盘。
- 建立 7 天单篇作文训练计划。
- 建立素材库、能力画像和成长记录。
- 建立账号、数据归属和个人中心。
- 建立可部署、可持久化、可验证的线上运行环境。
- 保留可解释的 AI 结果，不把生成内容伪装成学生真实经历。

## 三、当前技术架构

项目采用 Node.js + Express 单体架构，前端为原生 HTML、CSS 和 JavaScript，没有 React/Vue 构建链。该结构适合当前 MVP：部署简单、调试直接、前后端合同集中。

```text
浏览器页面
  -> public/*.html / *.js / *.css
  -> Express API（server.js）
  -> 账号、会话和数据归属检查
  -> lib/*.js 业务模块
  -> OpenAI-compatible AI 接口（当前默认 DeepSeek）
  -> 结果归一化、规则检查和状态写回
  -> 本地 JSON 或 Cloudflare D1
```

主要技术组成：

| 层级 | 当前实现 |
| --- | --- |
| 前端 | 9 个 HTML 文件、20 个 JavaScript 文件、7 个 CSS 文件；包含主页面和兼容页面 |
| 后端 | `server.js` 集中提供 API、鉴权、状态和 AI 编排 |
| 业务模块 | `lib/` 下 18 个 JavaScript 业务模块，覆盖检测、诊断、改写、事实检查、风格和长期能力 |
| AI | OpenAI-compatible Chat Completions；写作辅导、检测和改写可分别配置模型 |
| 本地状态 | `data/app-state.json`，仅用于本地开发 |
| 云端状态 | Cloudflare D1：`APP_STATE_DB -> inkedge-state` |
| 云端运行 | Cloudflare Worker `inkedge`，自定义域名 `inkedge.aicreatorhome.cn` |
| 认证 | 邮箱验证码、HttpOnly 会话 Cookie、服务端限流 |
| 邮件 | SMTP 配置通过环境变量和 Cloudflare Secret 管理 |
| 自动化资产 | `scripts/` 下 33 个 JavaScript 脚本，包含接口、合同、浏览器和真实 AI 测试 |

当前服务端注册 55 条路由，其中 29 条属于 `/api/v1` 作文训练与成长接口。另有 5 条历史算力相关路由仅保留为 `410` 下线兼容响应，不属于现行功能。

## 四、已完成功能

### 4.1 首页与工作台导航

已完成学习总览、作文构思、作文修改、素材库、写作计划和成长记录六个主要入口。页面文案已经从历史名称逐步统一；顶部“学习档案”已改为“个人中心”。

当前首页会根据用户状态显示游客或登录账号。游客点击账号入口打开登录/注册；已登录用户点击账号名称直接进入个人中心。

状态：**已完成并已在线确认。**

### 4.2 作文构思

用户可以填写作文标题、年级、文体和可选的真实素材。系统先生成多个立意方向，学生选择方向后再生成素材追问，不会在没有选择立意时直接进入泛化提问。

已完成功能：

- 支持小学三年级至高中三年级。
- 支持记叙文、议论文、读后感、材料作文和散文。
- 支持输入已有真实素材。
- 生成多个立意方向并由学生选择。
- 围绕选定立意生成素材追问。
- 支持补充素材和继续回答。
- 生成提纲树和分段写作提示。
- 每段提供独立输入区域，最后合并草稿。

状态：**已完成。接口、假模型、真实模型历史测试和浏览器流程均有通过记录。**

### 4.3 作文体检

用户提交完整草稿后，系统生成结构化体检报告，包括总体评价、维度分数、优先问题、相关片段和建议修改路径。

体检报告不是单独的展示终点。其优先问题会继续传递给局部修改和参考稿模型，保证后续建议与最初诊断一致。

状态：**已完成。**

### 4.4 局部修改建议

“生成局部修改建议”只有在体检报告返回后才可用，并位于体检优先问题区域下方。用户可以选择修改目标和修改深度，也可以输入自定义目标。

局部建议包含：

- 问题说明。
- 修改策略。
- 示例修改。
- 学生下一步行动。
- 新增描写核对提醒。

普通模式允许合理补充描写；显式严格事实模式会限制新增未经原文提供的人物、地点、时间、事件和结果。

状态：**已完成。**

### 4.5 参考对照

参考对照已形成独立页面，展示作文原稿、AI 参考稿、本次局部建议、体检优先问题和改动说明。

本期关键改进包括：

- 参考对照入口只在局部修改建议生成后出现。
- 模型同时接收局部修改建议和体检报告优先问题。
- 参考稿允许对事件、人物、细节、结构和表达进行更充分调整，不再被旧版事实边界提示过度限制。
- 返回链接统一指向 `/app.html`。
- 页面支持浅色和深色主题。
- 提供生成状态、错误重试和复制参考稿。

状态：**功能实现完成并已在线确认。** 真实模型输出质量具有随机性，仍需作为运营期持续抽样指标，而不是代码未完成功能。

### 4.6 素材库

用户只需要输入真实事件和细节，系统自动生成素材标题、场景、分类、适合题目、适配理由、关键词和可写角度。模型不可用时会标记本地降级，避免把规则结果伪装成真实 AI 结果。

状态：**已完成。**

### 4.7 7 天单篇作文训练

训练计划固定围绕一篇作文分 7 个阶段推进：

| 天数 | 阶段 | 主要产物 |
| --- | --- | --- |
| Day 1 | 选择立意 | 多个立意方向、选定方向 |
| Day 2 | 素材追问 | 问题和学生回答 |
| Day 3 | 提纲结构 | 提纲树 |
| Day 4 | 段落提示 | 各段写作提示 |
| Day 5 | 分段草稿 | 分段输入、合并草稿和反馈 |
| Day 6 | 草稿诊断 | 总评、维度分数和优先问题 |
| Day 7 | 修改复盘 | 修改稿、所学方法和下一步重点 |

服务端保存阶段输入、阶段产物、完成阶段和当前阶段，并阻止跳过必要顺序。前端提供专属状态机，不会在生成后立即跳走导致结果闪过。

状态：**核心流程完成。** Day 5 当前以分段输入、合并和反馈为主，未来可继续增强逐段 AI 陪写深度，但不影响本期结项。

### 4.8 能力画像与成长记录

系统支持初始能力测评、八维能力画像、优势和短板、训练重点、阶段复盘、成长时间线和下一步建议。成长记录由作文体检、训练计划、训练提交和复盘等真实业务记录聚合，不再固定返回空数据。

状态：**已完成基础闭环。** 长期趋势的说服力取决于用户持续使用产生的数据量，属于运营效果，不是本期开发缺口。

### 4.9 邮箱登录、个人中心与管理员

已完成邮箱验证码登录/注册界面、发送验证码、验证登录、会话 Cookie、退出登录、用户名修改和管理员用户管理。

安全与归属规则：

- 已登录用户数据统一按服务端认证账号 ID 归属。
- 不接受客户端伪造 `userId` 获得他人数据。
- 游客数据在登录成功后迁移到对应账号。
- 管理员权限由服务端校验。
- 验证码和认证接口具备限流状态。

状态：**已完成。SMTP 模拟端到端测试已通过；真实邮件服务投递率需运营期持续观察。**

### 4.10 计费边界

当前项目不使用算力计费。工作台和个人中心已移除算力、余额、费率、转账备注、流水、临时 IP 额度和管理员调额度内容。检测、改写和训练链路不再检查或扣减余额。

个人中心保留微信收款码图片，但它不构成当前自动计费、充值或功能解锁机制。历史 D1 字段保留用于兼容，业务不再读取或展示。历史算力接口返回 `410`。

状态：**已完成并已在线确认。**

### 4.11 主题、响应式与可用状态

主工作台和参考对照页支持浅色/深色切换并记忆用户选择。页面具备加载、空状态、错误提示、重试和禁用状态。主要页面有移动端基础布局，参考对照在窄屏下由双栏切换为单栏。

状态：**已完成基础适配。** 全机型视觉精修属于持续优化范围。

## 五、数据归属与安全完成情况

项目已形成以下安全边界：

- `.env`、本地状态和训练日志不进入公开代码。
- Cloudflare Secret 只核对名称，不在报告中打印值。
- 邮箱验证码、API Key、SMTP 密码和用户正文不写入测试报告。
- 作文会话通过服务端归属检查，不能只凭 `sessionId` 跨账号访问。
- 游客记录通过 Cookie 标识，登录后迁移到真实账号。
- 管理员接口需要管理员身份。
- 下线的计费接口返回明确的 `410`，避免前端误用旧协议。
