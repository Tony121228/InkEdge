# 全功能问题修复冒烟测试报告-1

检查日期：2026-09-13  
检查环境：Windows 本地项目 `D:\tony\黑客松项目`，Node.js 本地服务临时端口，部分测试使用 `.env` 中的真实 AI 配置。  
检查类型：本轮问题修复后的冒烟测试与回归测试。

## 一、修复内容概览

1. 短期写作引导拆分模型调用
   - `guided-writing` 不再把提纲树和段落写作提示塞进一次长输出。
   - 现在先生成提纲树，再基于提纲生成段落提示，降低长 JSON 输出解析失败概率。

2. 作文会话归属隔离
   - 所有 `essay-sessions/:sessionId` 相关接口改为校验当前用户归属。
   - 非本人会话读取、写入、体检、引导会返回稳定错误，不会串改他人数据。

3. 素材库重做为“只输入素材”
   - 前端移除素材标题、场景分类、适合题目三个输入框。
   - 后端新增“素材智能分类与题目生成”模型调用。
   - 保存素材时自动生成标题、场景、分类、适合题目、题目理由、关键词和可写角度。

4. 成长地图改为读取真实记录
   - `growth/timeline` 不再只返回空占位。
   - 会基于能力测评、作文体检、训练计划、训练提交和复盘生成时间线。

5. 前端 UI 细节修复
   - “我还没写”年级下拉补充三年级、四年级、五年级、六年级。
   - 作文体检分数卡支持对象型分数字段，展示分数、等级、证据和下一步建议。
   - 能力诊断页展示八维能力画像，不再只有阶段、优势、短板三行。

6. 局部修改事实边界收紧
   - 局部修改请求会把完整草稿传给模型。
   - 提示词明确要求不得新增人物、地点、时间、事件、结果、对话、心理变化或关键物件。
   - 如需要新事实，只能引导学生补充，不能写进示范修改。

7. 训练计划只保留 7 天
   - 后端 `POST /api/v1/training-plans` 明确拒绝 `14d`、`30d` 等历史类型。
   - 业务模块内部也固定为 7 天计划，避免旧参数绕过入口。
