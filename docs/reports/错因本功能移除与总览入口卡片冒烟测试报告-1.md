# 错因本功能移除与总览入口卡片冒烟测试报告

## 基本信息

- 测试日期：2026-09-06
- 项目：InkEdge 作文训练系统
- 范围：主应用页面、前端 API 客户端、服务端 V1 API、长期能力模块、总览页入口卡片

## 修改目标

1. 让“错因本”及其当前相关功能从产品中消失。
2. 将原本空的“总览”页改为主要功能入口卡片区。
3. 总览卡片样式沿用当前 `feature-card` 视觉体系，保持与其他卡片统一。

## 失败测试验证

修改前先补充测试并确认失败：

- `npm run test:short-guidance-frontend`
  - 失败原因：`app.html` 仍暴露“错因本”。
- `npm run test:essay-guidance-missing-key`
  - 失败原因：`GET /api/v1/error-notebook` 仍返回 `200`，说明后端接口仍可用。

## 实际修改范围

- `public/app.html`
  - 删除左侧导航“错因本”。
  - 删除 `view-notebook` 页面区块。
  - 将“学习总览”中的空面板替换为四张主要功能卡片：
    - 我还没写
    - 我写完了
    - 素材库
    - 训练计划
- `public/app.js`
  - 删除功能矩阵中的“错因库与个人问题本”。
  - 删除 `renderNotebook()`。
  - 删除 `renderDashboard()` 中对错因本渲染的调用。
  - 新增总览卡片导航绑定：点击卡片按钮后切换到对应功能页。
  - 将旧总览空面板相关渲染函数改为元素存在才渲染，避免空引用。
- `public/api-client.js`
  - 删除 `getErrorNotebook()`。
  - 删除 `createErrorNotebookItem()`。
- `server.js`
  - 删除 `GET /api/v1/error-notebook`。
  - 删除 `POST /api/v1/error-notebook/items`。
  - 从默认状态集合中移除 `errorNotebookItems`。
  - `dashboard` 不再返回 `recentIssues` 作为错因本数据。
- `lib/long-term-ability.js`
  - 删除错因库统计函数。
  - 删除成长轨迹中对 `errorNotebookItems` 的聚合和“错题终结者”徽章。
- `public/styles.css`、`public/app-apple.css`
  - 删除错因本专用样式。
  - 增加 `overview-feature-grid`，让总览四张功能卡片整齐排列。
