# 移除算力计费与账号归属冒烟测试报告-1

## 1. 执行范围

本次验证覆盖：

- 个人中心保留微信收款码图片，但不显示收费说明、费率、转账备注、余额、流水或临时额度。
- 工作台登录按钮：游客打开登录注册，已登录用户进入个人中心。
- 已登录用户的数据归属使用真实账号 ID，不接受客户端伪造的 `userId`。
- 游客写作数据在邮箱验证码登录成功后迁移到对应账号。
- 检测、改写、训练接口不再执行算力余额预检或扣减。
- 历史算力接口和管理员临时 IP/调额度接口返回 `410` 下线响应。

## 2. 代码修改

- `server.js`
  - 增加统一 `req.auth` 初始化。
  - `currentStudentId()` 登录时使用真实用户 ID，匿名时使用游客 Cookie。
  - 登录成功后绑定游客作文、素材、能力、训练和改写任务记录。
  - `/api/me` 和用户序列化不再返回余额、额度和流水字段。
  - 保留 `/api/payment/config`，只返回二维码路径和非收费名称。
  - 停止检测、改写、训练链路的额度检查和扣减。
  - 旧算力/临时 IP 管理接口返回 `410`。
  - 补齐改写任务基础生命周期，避免后台改写路由因未定义函数直接报错。
- `public/account.html`、`public/account.js`
  - 保留微信收款码。
  - 删除收费说明、费率、转账备注、余额、算力流水、临时 IP 面板和调额度控件。
  - 管理员只保留账号资料编辑和账号删除。
- `public/auth.js`、`public/app.html`
  - 删除登录赠送算力和游客试用额度文案。
  - 已登录账户按钮跳转 `/account.html`。
- 测试脚本
  - 新增 `scripts/account-ownership-and-no-billing.test.js`。
  - 更新匿名测试以保留服务端下发的游客 Cookie。
  - 更新旧算力接口和临时 IP 测试为 `410` 下线契约。
