# UI改版计划（青春配色与信息可视化）

日期：2026-08-24 02:41:41（Asia/Shanghai）
负责人：前端/UI 整合

## 一、背景与目标
- 当前问题：
  - 页面以文字为主，视觉层级弱，难以快速扫读；
  - 整体偏暗且理性，缺少“阳光、青春、活力”的感受；
  - 部分模块在未加载数据时显得空，缺少引导或占位；
  - 可点击区域与表单的可感知性不足，导致“看不出能做什么”。
- 改版目标：
  - 让首屏 5 秒内明确“我能做什么”（构思/体检/修改/训练）；
  - 降低文字密度，增加图标/卡片/进度条等视觉元素；
  - 默认使用更明亮的青春配色（保留深色模式），突出主题色；
  - 重要操作有明确主按钮和视觉通道；
  - 不改变后端接口与路由，前端以样式与结构微调为主。

## 二、设计原则
- 信息分层：标题>分区>卡片>说明，减少长段文本；
- 渐进呈现：用空态/占位卡引导下一步操作；
- 可视化指标：用“卡片+数值+条形/进度”代替大段文字说明；
- 一致性：采用统一的色板与组件样式；
- 可达性：保证对比度、键盘焦点、hover/focus 态清晰。

## 三、配色与主题（建议 tokens）
- 主题色（青春/阳光）：
  - `--mint`  #1DBA9B（活力薄荷）
  - `--sky`   #2F80ED（晴空蓝）
  - `--lemon` #FFC247（明亮柠檬）
  - `--coral` #FF7A59（珊瑚橙，用于提示与 CTA）
- 文字/线与背景：
  - `--ink`   #172033（正文深色）
  - `--muted` #667085（说明文字）
  - `--line`  #D7DFEC（分隔线）
  - `--paper` rgba(255,255,255,0.96)（卡片底）
  - `--body-bg` 渐变：从 #F6FBFF → #E9F4FF（晴空感）
- 模式：默认 Light（青春配色），保留 Dark 并维持切换。
> 实现方式：在 `public/styles.css` 的 `:root` 与 `html[data-theme="light"]` 中重定义变量；仅调整 tokens，不大改 DOM。

## 四、组件级改造
1) 顶部品牌区（Header）
- 新文案保留“墨锋InkEdge”，加入轻微背景光斑。
- 右侧保留登录与模式切换；按钮使用主色描边与 hover 强反馈。

2) 首屏（Dashboard Hero）
- 大标题简短：墨锋InkEdge；
- 副标题一句动作型话术（如“从构思到修改到复盘，一步到位”）。
- 今日重点卡片进度色条使用 `--sky` 渐变。

3) 快速入口（四宫格 CTA）
- 新增 4 张入口卡片：构思/体检/修改/训练；
- 含图标、一句话说明、按钮，跳转到对应视图。

4) 表单区（“我还没写 / 我写完了”）
- 字段组加 `fieldset` 与分组标题；
- 输入框加前缀小图标与清晰 placeholder；
- 主按钮使用 `--sky`/`--mint`，次按钮描边灰；
- 空态显示卡片式引导与示例。

5) 统计/成长卡片
- 数值+mini 进度条表达完成度；
- 常见问题/错因本用“问题类型徽标+一句话”列表。

6) 左侧导航
- 每个入口配 16px 简单图标（本地 `assets/icons`）；
- 当前态主色高亮，hover 背景高亮。

## 五、实施里程碑（两迭代）
- 迭代一（1–2 天）：
  1. 定义与落地新的 CSS 变量；
  2. 默认 Light 模式；
  3. Hero/今日重点配色与按钮状态；
  4. 空态占位与可点击反馈；
  5. 冒烟：导航切换、输入框可见、主按钮可点。
- 迭代二（2–3 天）：
  1. 快速入口四宫格与小图标；
  2. 表单分组与图标输入框；
  3. 卡片信息可视化（mini 进度条、徽标）；
  4. 登录弹窗与账户页跟进；
  5. 可访问性与移动端检查。

## 六、验收清单
- 首屏 5 秒可理解可操作（4 个入口一目了然）；
- 主要表单字段可见且操作显著；
- Light 默认、Dark 可切换；
- hover/focus 态明显；
- 无遮挡与不可点问题。

## 七、回滚/风险
- 风险：亮色主题与现有暗色主题并存时对比度不足；
- 策略：保留旧 tokens 便于一键回滚；按组件逐步发布；
- 不改动后端接口与数据结构。

## 八、下一步实施建议（代码级）
- 在 `public/styles.css`：新增青春配色变量组、补充 hover/focus/active。
- 在 `index.html`：首屏下新增“快速入口”卡片容器与锚点。
- 在 `app.js`：为四个入口按钮绑定视图切换（合并 nav-hotfix）。

## 九、置信度评估
- 置信度：0.84（在保持 DOM 基本不变的前提下可落地；移动端需实测）。
