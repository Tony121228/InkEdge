# 长期能力计划-冒烟测试-1

时间：2026-08-24T09:33:18.808Z

## 目标
- 通过 API 生成 7 天训练计划，并能作为 Active 计划返回给前端。

## 步骤
- 本地启动 Express 应用（端口随机）。
- POST `/api/v1/training-plans`，参数：`{ planType: "7d", dailyMinutes: 20, focusDimensions: ["素材具体度","语言自然度"] }`。
- GET `/api/v1/training-plans/active`。

## 结果
- 创建返回 200，`days.length === 7`。
- Active 返回 200，`id` 与创建一致，包含 `days` 数组。

## 结论
- 服务端可以生成完整 7 天计划并提供给前端读取，展示字段齐全（`planType/startDate/days[].taskId/title`）。
